# EnterCalc Privacy Policy

Last updated: March 23, 2026

EnterCalc does not collect, store, transmit, or share personal information or other user data.

EnterCalc:

- does not require an account
- does not use analytics, advertising, or tracking SDKs
- does not use third-party crash reporting services
- does not send calculator inputs, history, memory values, settings, or clipboard data to any server
- does not sell, share, or disclose user data to third parties

EnterCalc is intended to operate entirely on-device.

If these data practices change in a future release, this privacy policy will be updated before that release is distributed.
