# Contributing to EnterCalc

## Issues

Issues are the preferred way to report bugs, request features, and discuss changes.

Before opening a new issue:

- Search existing issues first.
- Include the app version, device, OS version, and steps to reproduce.
- Describe the expected result and the actual result.

Open an issue here: [github.com/tipliai/enterCalc/issues](https://github.com/tipliai/enterCalc/issues)

## Pull Requests

External pull requests are not the default contribution path for this repository.

If you want to propose a code change:

- Open an issue first and wait for maintainer confirmation before spending time on a PR.
- Pull requests that are not discussed in advance may be closed without review.

## Security

Do not include secrets, signing assets, provisioning profiles, or private credentials in issues or pull requests.
