# Security Policy

## Supported Versions

This project is under active development.

Security fixes are applied to:

- the latest code on `main`
- the `release` branch, if it is being used to maintain a shipped release

Older snapshots, historical tags, and unmaintained branches are not supported.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in EnterCalc, please report it privately.

- Email: support@tipli.ai
- Subject: `EnterCalc Security Report`

Please include:

- a description of the issue
- affected version, platform, commit, or branch if known
- reproduction steps or proof of concept

Please do not open a public GitHub issue for a suspected security vulnerability.

## Response Expectations

We will review reports and aim to acknowledge valid submissions as quickly as practical.

## Scope

This policy applies to the EnterCalc repository and official releases   of this project only.
